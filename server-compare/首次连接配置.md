## 4. 首次连接会自动发生什么

1. 客户端连服 → 服务端下发 manifest v1（238 条，229 条要求客户端）
2. 客户端按 modId 对比：
   - 下载 `byepregen 1.1.3.2`、`serverwarashi 2.1.1.4`、`create-dyn-light`
   - 删除 `byepregen 1.1.3.0`、`serverwarashi 2.1.1.2`、`c6c-1.2.2.1`
   - 其余 21 个客户端独有 mod 保留不动
3. 客户端提示重启 → 重启后进服 → 建立 baseline（首次成功进服后才有基线）

## 5. 建议在首次连接前完成的事

1. **客户端删掉 `c6c-1.2.2.1.jar`**（重复 modId，必须）
2. 服务端确认 `20016 → 8899` 端口映射与防火墙放行
3. 服务端 `custom_sync/mods/ignore/` 放入 `create-dyn-light`、`CustomSkinLoader`（空文件即可，文件名即匹配片段）——避免客户端被要求安装这两个服务端侧的 mod
4. 可选：清理服务端 3 个未进 manifest 的旧 jar（`CreateFastSchematicCannon-1.4.1`、`copycats` 无前缀版、`CustomSkinLoader_Universal` 保留服务端即可），减少混淆
5. 客户端 21 个多余 mod 不强制清理；如果追求两端完全一致，可后续逐个与服务端对齐

## 6. 首次连接 SOP

1. 服务端：把 `server-config/config/automodsync-common.toml` 放到 `D:\Server\config\`（覆盖前备份）
2. 服务端：把 `server-config/custom_sync/mods/ignore/` 下的两个空文件放到 `D:\Server\automodsync_server_storage\custom_sync\mods\ignore\`
3. 服务端：`run.bat` 启动，日志出现 `AutoModSync: HTTP Server STARTED on port 8899` 和 `Initial baseline v1 is trusted as VERIFIED` 即正常
4. 本机验证：`curl http://lt.cencenc.com:20016/diff?ver=0` 应返回 manifest JSON
5. 客户端：删 `c6c-1.2.2.1.jar` → 启动 → 连接 `lt.cencenc.com:20011`
6. 客户端 AutoModSync 界面会显示「版本同步：有新版本」→ 执行下载 → 重启
7. 重启后进服，OP（权限等级 4）会收到管理员验证请求 → 确认 → baseline 建立
